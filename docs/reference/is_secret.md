# Test whether an object is an orchrd_secret

Test whether an object is an orchrd_secret

## Usage

``` r
is_secret(x)
```

## Arguments

- x:

  Any object.

## Value

`TRUE` if `x` is an `orchrd_secret`, otherwise `FALSE`.
